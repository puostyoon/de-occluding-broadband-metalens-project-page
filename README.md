# De-occluding Broadband Metalens — Project Page

Static GitHub Pages site for **De-occluding broadband metalens**, Nature Communications **17**, 9808 (2026). The page uses a restrained, figure-led academic layout and requires no build step.

## Website

[Project page](https://puostyoon.github.io/de-occluding-broadband-metalens-project-page/) · [Final paper](https://www.nature.com/articles/s41467-026-76606-0)

The paper preview is the full first page of the official Version of Record PDF, published in final form on 15 September 2026. Bibliographic fields follow the publisher's downloadable citation.

## Publish with GitHub Pages

1. Copy the contents of this folder to the root of a GitHub repository.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save.
4. The canonical and social image URLs already point to the public project-page address above.

## Structure

- `index.html` — page content and section order
- `assets/css/style.css` — typography, scientific figures, and responsive layout
- `assets/js/main.js` — method sequence, video coordination, lightbox, and BibTeX copy
- `assets/derived/` — web crops and composites derived from the paper, presentation, and supplementary PPT
- `assets/video/` — compressed supplementary videos

The page uses real scientific images and measurements supplied with the paper. No AI-generated scientific result or experimental image is included.
